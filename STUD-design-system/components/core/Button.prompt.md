`Button` is the only action control. Labels are sentence case — never uppercase them.

```jsx
<Button size="xl" block trailing="→">Estudar 40 minutos</Button>
<Button variant="light">Filtros</Button>
<Button variant="outline" size="sm">Descartar</Button>
```

Pick the variant by background: `ink` on cream/white, `light` on a colour canvas,
`spring`/`sun` for the one celebratory action, `outline`/`ghost` for secondary.
`sticker` gives the outlined hard-shadow look — at most one per screen.
