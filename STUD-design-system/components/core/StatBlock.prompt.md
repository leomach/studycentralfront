`StatBlock` for a headline number; `StatBox` for a row of two-to-four bordered cells.

```jsx
<StatBlock value="18" label="dias seguidos" size="lg" />
<StatBlock value="06:12" label="tempo usado" mono />
<div style={{display:"flex",gap:8}}><StatBox value="41" label="questões / 7 d" /><StatBox value="74%" label="acerto" /></div>
```
