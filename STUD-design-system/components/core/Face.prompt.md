`Face` is how STUD shows feeling. Pair it with a poster headline on a colour canvas;
use it small (40–56px) as a session state marker. Never use emoji instead.

```jsx
<Face mood="focus" size={220} />
<Face mood="happy" size={48} tone="light" />
```

Moods: `happy` (streak, correct), `calm` (idle/empty), `focus` (session running),
`wow` (milestone), `sleepy` (nothing due), `tough` (a hard card returning).
